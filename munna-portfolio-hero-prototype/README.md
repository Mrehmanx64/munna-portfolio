# Munna — Portfolio Hero Prototype

A responsive, dark editorial portfolio hero built with plain HTML, CSS and JavaScript.

## Run
Open `index.html` directly in a browser, or use VS Code Live Server.

## Files
- `index.html` — hero structure and placeholder copy
- `styles.css` — grid, typography, portrait composition and responsive layouts
- `script.js` — mobile navigation and subtle background type parallax
- `assets/munna.png` — supplied transparent portrait

## Quick edits
- Replace `CREATIVE` / `MINDSET` with your preferred oversized background words in `index.html`.
- Replace the Lorem ipsum paragraph and headline copy in `index.html`.
- Update the email address (`hello@example.com`) in the header and CTA.
- Adjust portrait size with `.portrait-wrap` in `styles.css`. It is intentionally oversized and centered.
- Change the accent color via `--accent` near the top of `styles.css`.
